# Toolkit

Python-пакет с CLI, который содержит калькулятор и конвертер единиц измерения.

## Калькулятор

Калькулятор поддерживает:

* сложение `+`
* вычитание `-`
* умножение `*`
* деление `/`
* приоритет операций
* положительные и отрицательные числа
* пробелы в выражении

Примеры:

```bash
python3 -m toolkit calc "2+3*4"
```

Результат:

```text
14.0
```

```bash
python3 -m toolkit calc "10 / 4"
```

Результат:

```text
2.5
```

## Конвертер

Конвертер поддерживает три группы единиц.

### Длина

* `mm`
* `cm`
* `m`
* `km`

### Масса

* `g`
* `kg`

### Температура

* `c`
* `f`
* `k`

Регистр единиц измерения не учитывается.

Примеры:

```bash
python3 -m toolkit convert 1000 --from mm --to m
```

Результат:

```text
1.0
```

```bash
python3 -m toolkit convert 1.5 --from kg --to g
```

Результат:

```text
1500.0
```

```bash
python3 -m toolkit convert 0 --from c --to f
```

Результат:

```text
32.0
```

Температура ниже абсолютного нуля запрещена.

## Обработка ошибок

Программа обрабатывает ошибки при:

* пустом выражении;
* неправильных операциях;
* делении на ноль;
* недопустимых символах;
* неправильных числах;
* неизвестных единицах измерения;
* конвертации между несовместимыми группами;
* температуре ниже абсолютного нуля.

При ошибке CLI возвращает код `2`.

## Установка

Для установки проекта используется:

```bash
pip install -e .
```

После установки можно запускать программу:

```bash
python3 -m toolkit calc "2+3*4"
```

## Тестирование

Для запуска всех тестов:

```bash
python3 -m pytest tests -v
```

Для запуска тестов калькулятора:

```bash
python3 -m pytest tests/test_calculator.py -v
```

Для запуска тестов конвертера:

```bash
python3 -m pytest tests/test_converter.py -v
```

Для запуска тестов CLI:

```bash
python3 -m pytest tests/test_cli.py -v
```
